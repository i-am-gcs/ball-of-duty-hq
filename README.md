# Ball of Duty HQ

React + Vite alapú klubmenedzsment MVP a Ball of Duty CF számára.

## Funkciók

- reszponzív Dashboard
- működő React Router navigáció
- játékoskeret kereséssel és pozíciószűrővel
- szezonarchívum
- szezon játékosa szavazás localStorage mentéssel
- interaktív Benefit Tracker
- játékos- és csapatstatisztikák
- szerkeszthető beállítások

## Indítás

```bash
npm install
npm run dev
```

Ezután nyisd meg a terminálban megjelenő localhost címet.

## Build

```bash
npm run build
npm run preview
```

- Supabase adatbázis és autentikáció
- Discord-integráció
- EA / FC statisztikai adatforrás
